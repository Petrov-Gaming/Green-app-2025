# 🌍 Green App 2025

A Python/Flask web app for tracking carbon emissions. This is the 2025 version of the project and is still being built.

![Python](https://img.shields.io/badge/Python-3776AB?logo=python&logoColor=white)
![Flask](https://img.shields.io/badge/Flask-000000?logo=flask&logoColor=white)
![HTML5](https://img.shields.io/badge/HTML5-E34F26?logo=html5&logoColor=white)
![CSS3](https://img.shields.io/badge/CSS3-1572B6?logo=css3&logoColor=white)

## ✨ Features

- **Home page:** landing page with project info
- **Carbon app:** module for logging emissions
- **Registration:** user sign-up
- **Methodology:** explains how emissions are calculated

## 🧱 Tech Stack

Python · Flask (Blueprints) · Jinja2 · HTML/CSS

## 📁 Project Structure

```
Capp/
├── home/          # landing page
├── Carbon_app/    # emission tracking
├── register/      # user registration
├── Methodology/   # calculation method
├── templates/     # HTML templates
└── static/        # CSS & icons
```

## 🚀 Getting Started

```bash
git clone https://github.com/Petrov-Gaming/Green-app-2025.git
cd Green-app-2025
python3 -m venv venv
source venv/bin/activate        # Windows: venv\Scripts\activate
pip install flask
flask --app Capp run
```
